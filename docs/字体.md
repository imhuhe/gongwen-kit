# 字体

## GB/T 9704 规定的用字与实现对照

| 要素 | 国标（条款） | 本工具声明 | 说明 |
|---|---|---|---|
| 正文 | 3 号仿宋体字（7.3.4） | `FangSong` | Windows 内建「仿宋」 |
| 标题 | 2 号小标宋体字（7.3.1） | `方正小标宋简体` | 公文环境通行字体，见下节 |
| 层次序数 | 一层黑体／二层楷体／三四层仿宋（7.3.3） | `SimHei`／`KaiTi`／仿宋 | Windows 内建 |
| 发文机关标志 | 小标宋（推荐）、红色（7.2.4） | 同标题 | |
| 密级、紧急程度 | 3 号黑体（7.2.2、7.2.3） | `SimHei` | |
| 发文字号 | 仿宋（7.2.5） | `FangSong` | |
| 签发人 | 「签发人」仿宋、姓名楷体（7.2.6） | `FangSong`／`KaiTi` | |
| 页码 | 4 号半角宋体（7.5） | `SimSun` | Windows 内建「宋体」 |
| 版记 | 4 号仿宋（7.4.2、7.4.3） | `FangSong` | |

字体名用 Windows/Office 通行写法（英文名与中文名互认）；方正小标宋两处
（标题、机关标志）可分别用环境变量整体替换，见下。

## 方正小标宋的授权与替代

方正小标宋简体属方正字库，个人免费授权不含商业使用。本工具**只声明字体名、
不分发字体文件**——字体由目标机器自己提供。政府机关与央国企的电脑普遍装了
它，在这些机器上打开即标准效果。

没有这个字体的机器（例如 macOS）Word 会替换渲染。本机预览时用环境变量换一个
宋体骨架的替代字：

```bash
GONGWEN_FONT_TITLE="Songti SC Black" node 你的稿源.js
```

（macOS 自带、零下载；Windows 上照旧替换成宋体，仍是宋体骨架，比退化成
微软雅黑强。）

内网和离线机器：安装包与依赖的打法见 README「内网和离线安装」。字体仍由目标机器提供；
机器上没有方正小标宋、又不能下载字体时，用上面的环境变量换成机器上已有的宋体骨架字体，
并在导出 PDF 后用下面的检查核对实际渲染。

## 字体替换的验证

docx 里写的字体只是「请求」，实际渲染用了什么，只有导出 PDF 的内嵌字体说得清。
仓库带一个可选的 PDF 检查（需要 PyMuPDF）：

```bash
~/.venvs/pdf/bin/python3 tools/check-pdf.py 导出件.pdf [--allow "额外字体名"]
```

- 白名单见脚本顶部：国标五类字体 + 方正小标宋的常见文件名 + macOS 预览替代；
- 本机的替代字体（如 `Songti SC`）用 `--allow` 放行；
- 目标机器（装了方正字体）导出的 PDF 应能不加 `--allow` 直接通过——
  通不过说明字体没装上或名字对不上，别急着加白名单，先查字体。

除字体外，这个脚本还查三类烙印在分页上的版面问题：标题孤悬页底、
大片留白、空白页。分页是 Word 排出来的，docx 结构机检看不到。
