# 修复现成文件

`tools/fix-doc.js` 处理已经写好的 .docx（手写的、别人发来的、旧模板出的），
另存为「原名-修订.docx」，原文件不动。

```bash
node tools/fix-doc.js 稿子.docx --dry-run       # 预演：只报告，不写文件
node tools/fix-doc.js 稿子.docx                 # 输出 稿子-修订.docx
node tools/fix-doc.js 稿子.docx --out 新名.docx
node tools/fix-doc.js 稿子.docx --no-layout     # 只改体例、插批注，版式不动
```

## 三档处理

| 档 | 怎么改 | 范围 |
|---|---|---|
| 版式 | 直接改 | 版心与网格、正文与层次标题的字体字号、公文标题、页码、正文手设的字体字号与行距；表题/附件页/版记/纪要名单/份号密级/红头/表格/文本框保持原格式 |
| 体例与规范层文风 | 写成 Word 修订痕迹，在「审阅」里逐条接受或拒绝 | 下表各条 |
| 数字与要靠判断的项 | 不改，插批注 | 合计与分项、跨表同一指标、「以下三点」与实际条数、层次序数、数值范围写法等 |

数字一律不自动改。合计和分项对不上，错的可能是合计，也可能是某个分项，工具判断不了。

### 版式（直接改）

- **版心与网格**：A4，上 37、下 35、左 28、右 26 mm，每页 22 行、每行 28 字（各节都改）
- **样式**：默认字体仿宋三号；正文首行缩进二字、两端对齐、行距交给网格；
  层次标题一级黑体、二级楷体、三四级仿宋，三号，不加粗，去掉段前段后
- **公文标题**：前 15 个有字段落里第一个居中（解析样式链，Title 样式也算）、非红色、
  不像发文字号或日期的段落（连同紧接的居中段），改为小标宋二号、不加粗；标题上手设的
  行距交还网格
- **正文直接格式**：只有正文/层次标题的 run 字体字号交还样式、段落手设行距交还网格；
  表题、附件页、版记、纪要名单、份号密级、红头、表格、文本框不参与
- **缩进**：首行缩进二字加在默认样式上。原来不缩进的段落各自补「首行不缩进」，保持原样：
  主送机关（标题后第一段、以冒号结尾）、居中和右对齐的段落、表格和文本框里的段落、
  红头里的段落、用空格手动缩进的段落。段落上原本写了缩进的，按原值不动
- **页码**：「— 1 —」，宋体四号，单页居右、双页居左；原有页脚引用换成新页脚。
  打开单双页不同以后，只有默认页眉的节，双页沿用同一个页眉
- **条文体**：检测到正文 `第X章`/`第X条`，或自动编号 `lvlText` 里的 `第%1章`/`第%2条` 时，
  章标题用方正小标宋居中、条与项用仿宋，
  不再套行文体的一级黑体/二级楷体
- **信函/纪要**：自动跳过通用版式（避免把 30mm 版头、170mm 双线、纪要名单改坏）；
  确实要套通用版式时加 `--layout`
- **settings**：补单双页不同页眉页脚、标点压缩

### 体例（修订痕迹）

| 规则 | 改前 | 改后 |
|---|---|---|
| 月日编虚位 | 2026年05月08日 | 2026年5月8日 |
| 发文字号括号 | ×发【2026】12号 | ×发〔2026〕12号 |
| 发文字号「第」与虚位 | ×发〔2026〕第012号 | ×发〔2026〕12号 |
| 中文数字日期 | 二〇二六年十月十三日 | 2026年10月13日 |
| 全角数字 | 共１２个项目 | 共12个项目 |
| 半角括号 | 各县(市、区) | 各县（市、区） |
| 半角标点 | 现通知如下:一是,二是. | 现通知如下：一是，二是。 |
| 异形词（GF 1001 规范层） | 筹画项目 | 筹划项目 |
| 数字与单位 | 100kWh | 100 kWh |
| 纯小数 | 厚度.5毫米 | 厚度0.5毫米 |
| 标题重复编号 | 自动编号的标题里手写的「一、」 | 删去手写编号 |
| 斜体 | 斜体 | 正体（格式修订，拒绝后斜体回来） |

全部拒绝修订，正文逐字等于原文；这条由 `tests/fix.js` 断言。原稿里别人留下的修订原样保留，
「全部拒绝」只拒本工具（作者 gongwen-kit）的那一批。

### 批注

改完后对输出件重跑三道机检，剩下的每条命中插一条批注，挂在命中原文所在的段落上，
所以批注和机检的口径一致。一条命中涉及多处的，每处一条，最多 20 条。
标「提示（不一定错，请核对）」的批注不拦稿：

- 首行没声明表头的表（手写表常见），合计对不上只提示：跨页拆开的表、只列前几名的表，
  合计本来就不等于本页各项之和
- 百分比合计与分项对得上、但不到 100% 的，只提示：「前五名占比」这类表本来就是部分
- 正文同一指标多处取值、正文与表格取值不一致

## 不改什么

宁可不改，不能改坏。下面这些一律不动：

- **原话与引文**：「」、“”、《》里的文字照录（书名号里的「二〇三五年」不改）
- **网址、邮箱、文件名与裸域名**：`公文.docx`、`中文.com` 里的「.」不是半角标点
- **该保留的写法**：时刻 10:30、序号点「1.工作方案」、小数 2.5、英文缩写 e.g.、
  不带〇的「二零二六年」、非发文字号的方括号
- **留空待填**：「¥      .00元整」不补 0；被空格断开的「99 .8%」不补 0
- **段落里的不透明元素**：超链接、域、已有修订、图片、文本框。改动碰到它们就跳过，留给批注
- **表格里的文字与数字**：一个都不自动改；合计错、表内日期/数字写法只插批注
- **红头与版头**：红色段落（直接设红色的，或用了红色段落样式、字符样式的）、
  发文机关标志的尺寸与位置、份号/密级/紧急程度、发文字号、签发人、首页页脚。
  发文字号只在版头前 12 段、且整段是「字号」或「字号 + 制表位 + 签发人」时保护；
  正文「根据国办发〔2026〕5号要求……」是引用，不整段跳过修订
- **发文机关署名**：右对齐的署名按专名处理，不按异形词改；日期仍允许修
- **文本框**：不参与标题检测，格式与文字都不改
- **表格内部版式**：列宽、边框、单元格字号

## 已知限制

- 标题检测靠位置和对齐判断，封面页、目录页在前的文件可能认错或认不到；认错了在修订里拒绝即可，
  标题字体是直接改的，需要手动改回
- 跨表同一指标只比首行声明了表头的表，手写表不参与
- 合计列方向的检查跳过余额、期初、期末、累计、单价、比率类的行；跨年度表的合计列含表外年份时
  会给提示
- 版式按 GB/T 9704 处理：信函/纪要自动跳过通用版式，条文体按章/条映射；
  非公文企业文书（合同、简历）不要用默认 `fix`
- 标题识别按样式链和位置，封面页/目录页在前的文件仍可能认错；认错了在修订里拒绝即可
- 批注挂在整段上，不精确到字
- 红头的红色来自主题色（`w:themeColor`）而不是具体色值的，认不出是红头，会按正文改字体字号；
  遇到这种文件用 `--no-layout`，或在 Word 里把红头改回原样
- `--out` 不能等于原文件路径，工具会拒绝执行：输出件带修订痕迹，覆盖原稿就没有干净的底稿了

## 怎么验证的

- **规则标本**：每条规则一对「改前→改后」，外加该放过的写法，见 `tests/fix.js`
- **乱稿**：`tests/messy-docx.js` 造一份手写稿（中文样式 ID、宋体小四、1.5 倍行距、
  方括号发文字号、超链接、斜体、无表头的表、带别人修订的段落），断言全部拒绝等于原稿、
  全部接受后体例与规范层文风机检无剩余、批注都定位到原文
- **合规件**：本仓的七份样张（含条文体）修一遍，修订、批注都必须是 0，且逐段 pPr/run 格式
  与原稿相同（`tests/fix.js` 的 `paraSig`）；信函/纪要自动跳过版式，也不许改段落格式；
  公文管理办法另断言 `styles.xml` 的章标题 `jc=center`、字体为标题字体
- **角色保护**：红头机关名、右对齐署名、表格里的数字/日期不自动改；`--dry-run` 不写文件；
  `--out` 缺值/指向原文件返回 2（`tests/fix.js`）
- **真实文件回放**：两百多份日常业务 .docx（报告、可研、合同、申请表）跑一遍，0 崩溃，
  全部拒绝后与原稿逐段一致；抽样用 Word 打开、导出 PDF 核对显示
